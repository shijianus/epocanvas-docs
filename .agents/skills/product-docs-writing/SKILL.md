# 产品说明与技术文档写作规范 (Product Docs Writing Skill)

本技能为官方产品说明书与技术文档制定了严谨、接地气的编写规范。核心宗旨是：**讲人话、重实用、去虚浮、重实操**。

---

## 一、 语言与风格红线（反 AI 套话指南）

### 1. 严禁滥用的 AI 假大空词汇
- ❌ **禁止使用**：“四层全景系统工程架构”、“微秒级置换”、“双层降级容灾”、“沉浸式阅读黄金纵深”、“零感全球分发”、“极致丝滑体验”、“跨时代赋能”、“闭环矩阵”。
- ✅ **改为直白表述**：“系统架构由 4 个主要模块组成”、“切换语言无需刷新页面”、“找不到翻译时自动回退为中文”、“三栏布局让正文与目录一目了然”、“基于 Cloudflare Pages 全球 CDN 加速”、“本地加载快”。

### 2. 写作语气与视角
- **清晰客观**：以工程师和产品经理面向真实用户的口吻撰写，平实交代“这个功能是做什么的”、“在什么场景下使用”。
- **步骤明确**：操作步骤必须给出具体命令、点击路径和预期输出，而不是抽象的概念描述。
- **排版克制**：不要每一段都使用引语框（Blockquote）或大段加粗，重点突出，层次自然。

## 二、 产品说明标准结构

产品文档应遵循用户由浅入深的认知规律，划分为以下 7 个标准板块：

1. **产品简介与核心价值 (Overview)**：
   - 一句话说明这是什么产品。
   - 解决了用户的什么痛点（为什么做这个项目）。
   - 核心功能一览（界面导航、全文搜索、多语言、自适应主题、自动化部署）。
   - 真实产品界面图展示。

2. **快速上手 (Quickstart)**：
   - 本地运行所需环境（Node.js、pnpm）。
   - 3 步在本地跑起来（安装、启动、打开浏览器）。
   - 核心构建命令速查表。

3. **核心功能与使用说明 (Feature Guides)**：
   - 页面布局解析（顶部导航栏、左侧菜单、中央正文、右侧文章大纲）。
   - 全文搜索功能（如何使用 Cmd+K 搜索，搜索机制与效果）。
   - 多语言阅读（支持哪些语言，如何切换）。
   - 亮暗主题切换。

4. **文档编写与排版规范 (Authoring Guide)**：
   - 新增一篇文档的具体步骤与文件存放位置。
   - Frontmatter 元数据必填项与可选项。
   - Markdown 常用排版语法（标题、列表、表格、代码高亮、提示框）。
   - 图片与静态资源存放路径要求。

5. **系统配置与定制开发 (Configuration)**：
   - 站点主配置文件 `astro.config.mjs` 修改指南（网站标题、域名、Logo）。
   - 导航与菜单配置 `src/config/navigation.ts`（如何增删菜单项）。
   - 样式与外观定制 `src/styles/custom.css`（主题色修改）。

6. **发布与运维部署 (Deployment)**：
   - 如何部署到 Cloudflare Pages。
   - 绑定自定义域名的具体操作。
   - GitHub Actions 自动化发布流程说明。

7. **常见问题与排错指南 (FAQ & Troubleshooting)**：
   - 收集开发者和用户最常遇到的 4~6 个真实问题并给出解决方案。

---

## 三、 图片与图表示范规范

1. **图文强绑定**：插入的每一张图必须有针对性的文字说明，指出图中各个区域的含义，严禁为了凑图而堆砌无意义的装饰图。
2. **图表简洁直观**：使用 Mermaid 流程图或直观界面标注，展现清晰的调用关系或页面布局结构。

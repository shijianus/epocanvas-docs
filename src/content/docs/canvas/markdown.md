在 **EpoCanvas Docs** 中添加或编辑文档非常轻松。所有正文内容都用标准 **Markdown** 语法编写，只要你会写 Markdown，就能立即参与文档的撰写和维护。

## 1. 文档文件放在哪里？

所有文档文件都存放在项目的 `src/content/docs/` 目录下：

```text
src/content/docs/
├── index.mdx          # 网站的落地首页
└── canvas/            # 核心文档章节
    ├── index.md       # 产品简介
    ├── deployment.md  # 快速上手
    ├── layout.md      # 页面布局
    ├── ...            # 其他文档
```

- **文件名要求**：使用小写英文字母和中划线（例如 `quickstart-guide.md`），不要包含中文或空格。文件名决定访问路径：`canvas/deployment.md` 对应 `/canvas/deployment/`。
- **扩展名**：通常使用纯文本的 `.md` 文件即可；如果需要在文章中引入交互组件（如首页的卡片网格），使用 `.mdx` 格式。
- **登记侧边栏**：新建文件后，需要在 `astro.config.mjs` 的 `sidebar` 数组中登记，否则不会出现在左侧目录里。

## 2. 头部元数据 (Frontmatter) 怎么写？

每一篇 Markdown 文档的最上方，都必须包含用三个横线 `---` 包裹的 YAML 元数据块：

```yaml
---
title: 快速上手 (3分钟运行)
description: EpoCanvas Docs 本地环境准备、安装依赖与启动服务指南。
---
```

### 字段说明

| 字段名称 | 是否必填 | 作用说明 |
| :--- | :--- | :--- |
| `title` | **必填** | 文章主标题。渲染为页面顶部的大标题，并作为浏览器标签页标题。 |
| `description` | 建议填写 | 文章的简短摘要。用于浏览器搜索结果、社交平台分享卡片的描述文字。 |
| `template` | 仅首页使用 | 设为 `splash` 时使用无侧边栏的落地页模板。 |

:::tip
如果你写文档时漏写了 `title`，构建时 Astro 会在终端明确报错并指出文件名，按提示补上即可。
:::

## 3. 常用 Markdown 排版格式

### 3.1 标题层级

正文中**不要重复书写一级标题（`#`）**——Frontmatter 的 `title` 已经自动渲染为页面大标题，正文再写一个 `#` 会导致页面出现两个相同的大标题。

各级小节标题从二级标题（`##`）开始，右侧"本页目录"会自动抓取二级和三级标题：

```markdown
## 二级大标题（会被收录进右侧本页目录）

正文内容...

### 三级子标题（大纲中的缩进子项）

更细节的内容...
```

### 3.2 文字强调与行内样式

```markdown
这是**加粗文字**，这是*斜体文字*，这是~~删除线~~。
用行内代码标识符标记命令与文件名：`pnpm run dev`。
```

### 3.3 列表与任务清单

```markdown
无序列表：
- 第一项功能
- 第二项功能
  - 缩进子功能

有序列表：
1. 第一步：安装 Node.js
2. 第二步：克隆代码仓库

任务清单：
- [x] 已完成的事项
- [ ] 待办事项
```

### 3.4 表格排版

```markdown
| 参数名称 | 类型 | 默认值 | 说明 |
| :--- | :--- | :--- | :--- |
| `site` | string | 无 | 站点的线上生产域名 |
| `title` | string | 必填 | 网站标题 |
```

## 4. 如何在文档中插入图片？

把文档所需的图片资产统一放在 `public/images/canvas/` 目录下：

```text
public/
└── images/
    └── canvas/
        ├── screenshot.png
        └── diagram.svg
```

在 Markdown 中引用时，使用以 `/` 开头的绝对路径：

```markdown
![图片说明文字](/images/canvas/screenshot.png)
```

**图片规范**：

- **架构图与流程图**：保存为 `.svg` 矢量图，在手机和高清屏上放大不模糊。本站的架构图都在 `public/images/canvas/docs-*.svg`。
- **界面截图**：保存为压缩过的 `.png`，宽度 1440 像素左右即可，不要直接上传几十 MB 的原图。
- **描述文字必填**：`![ ]` 里的文字会渲染为图片的替代文本，请认真描述图片内容，不要留空。

图片插入后**务必在浏览器里实际查看渲染效果**，确认路径正确、图片显示正常再提交。

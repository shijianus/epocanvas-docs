# EpoCanvas Docs 产品说明书

**EpoCanvas Docs** 是专门为 EpoCanvas 开源生态打造的官方技术文档站点系统。它基于现代静态网站框架 **Astro 5** 和 **Starlight** 构建，旨在为开发者提供一个**排版专业、打开极快、搜索顺手、易于维护**的文档平台。

无论是编写产品的用户手册、API 接口规范，还是记录系统架构设计，EpoCanvas Docs 都能让撰写者专注于写好 Markdown 内容，同时为阅读者提供舒适自然的浏览体验。

---

## 解决的实际问题

在日常开发和技术写作中，许多团队在维护文档时常遇到以下困扰：

1. **页面打开慢、占用内存高**：很多文档工具生成的页面带有大量 JavaScript 运行时，手机或弱网环境下打开慢，滚动长文章时容易卡顿。
2. **长文章导航费劲**：常见文档站通常只有左侧菜单，阅读数千字的长篇技术说明时，难以快速了解当前文章内部的小标题层级。
3. **搜索依赖外部服务**：常见的 Algolia 等云端搜索服务需要额外申请账号、配置爬虫密钥，在内部网络或离线环境下完全失效。
4. **多语言切换体验生硬**：大部分文档站切换语言时必须重新加载整个网页，不仅耗费流量，还会重置用户的阅读进度和滚动位置。

EpoCanvas Docs 正是为了解决这些实际痛点而设计的。

## 核心功能一览

![EpoCanvas Docs 界面与布局展示](/images/canvas/docs-layout-3tier.svg)

### 1. 清晰的三栏式阅读界面
- **左侧导航栏**：按模块组织所有文档分类，带有层级折叠和滚动条记忆功能，换页不跳动。
- **中央正文区**：采用符合人体工学的大字号与行距排版，支持宽屏代码块自适应，长时间阅读眼睛不易疲劳。
- **右侧大纲栏**：实时抓取文章内的 `h2` 和 `h3` 标题，随着鼠标向下滚动自动高亮当前阅读位置，点击任意小标题即可平滑跳转。

### 2. 开箱即用的离线全文搜索
- 内置轻量级本地静态搜索引擎（Pagefind），不依赖任何后端数据库或外部 API。
- 支持键盘快捷键 `Cmd + K`（Mac）或 `Ctrl + K`（Windows/Linux）瞬间呼出搜索窗口。
- 输入关键词后即可看到匹配的文章与段落预览，高亮展示命中文字。

### 3. 10 种语言免刷新切换
- 支持简体中文、繁体中文、英语、日语、韩语、德语、法语、西班牙语、俄语、阿拉伯语共 10 种常用语言。
- 点击右上角语言切换按钮，页面文字直接就地更新，无需等待页面重新加载。

### 4. 专业的 Markdown 与代码排版
- 内置现代代码语法高亮，自带语言标识、行号显示和一键复制代码功能。
- 原生支持 5 种不同颜色的提示框（Note 提示、Tip 技巧、Important 重要、Warning 警告、Caution 危险）。
- 支持在 Markdown 中直接用文字画流程图、时序图（基于 Mermaid 渲染）。

### 5. 极速打包与一键边缘托管
- 基于 Astro 5 静态编译器，构建产物为纯净的 HTML、CSS 与 WebP 优化图片，打开几乎感觉不到延迟。
- 预置 Cloudflare Pages 部署命令，一行指令即可将文档推送到全球 CDN 节点，并享有免费的 HTTPS 证书。

## 项目整体架构

为了让文档保持高效与轻巧，系统采用了合理的模块划分：

![EpoCanvas Docs 系统架构图](/images/canvas/docs-architecture.svg)

- **底座与样式**：基于 Astro 5 静态内核，通过 `src/styles/custom.css` 定义设计变量，自动适应浅色模式与深色模式。
- **内容源管理**：所有文档均保存在 `src/content/docs/` 目录下，使用纯 Markdown（`.md`）或富交互（`.mdx`）撰写。
- **界面组件**：通过覆盖 Starlight 原生组件，定制了更加优雅的顶栏、侧边栏、大纲目录与搜索模态窗。
- **分发与访问**：编译产物保存在 `dist/` 目录，直接托管在 Cloudflare Pages 全球网络，国内与海外访问均非常顺畅。

## 专案目录结构

本专案的代码组织非常清晰直观，各目录分工如下：

```
epocanvas-docs/
├── public/                 # 静态资源目录（图片、矢量图标直接放这里）
│   └── images/canvas/      # 界面插图与系统拓扑图
├── src/
│   ├── components/starlight/ # 定制的页面组件（页头 Header、大纲 TOC、搜索框等）
│   ├── config/navigation.ts  # 顶部导航栏配置（增删菜单项改这里）
│   ├── content/docs/         # 文档正文 Markdown 文件存放位置
│   │   ├── index.mdx         # 文档站首页 Landing Page
│   │   └── canvas/           # 各章节文档
│   ├── styles/custom.css     # 全局样式与主题颜色设置
│   └── utils/i18n.ts         # 多语言字典文件
├── astro.config.mjs        # 站点主配置文件（标题、侧边栏目录在这里配）
└── package.json            # 专案依赖与运行命令配置
```

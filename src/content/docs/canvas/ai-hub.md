# 多语言支持与阅读切换

作为面向全球开发者的开源专案，**EpoCanvas Docs** 内置了简单好用的**多语言切换功能**。读者无论来自哪个国家，都能根据自己的阅读偏好，随时切换到熟悉的界面语言。

---

## 支持的语言列表

系统目前内置了 10 种全球主流语言支持：

| 语言代码 | 语言名称 | 简标 | 阅读方向 |
| :--- | :--- | :--- | :--- |
| `zh-CN` | **简体中文** (默认) | ZH | 从左至右 (LTR) |
| `zh-TW` | **繁體中文** | TW | 从左至右 (LTR) |
| `en` | **English (英语)** | EN | 从左至右 (LTR) |
| `ja` | **日本語 (日语)** | JA | 从左至右 (LTR) |
| `ko` | **한국어 (韩语)** | KO | 从左至右 (LTR) |
| `de` | **Deutsch (德语)** | DE | 从左至右 (LTR) |
| `fr` | **Français (法语)** | FR | 从左至右 (LTR) |
| `es` | **Español (西班牙语)** | ES | 从左至右 (LTR) |

## 如何在页面上切换语言

切换语言的操作非常直观：

![多语言切换工作机制示意图](/images/canvas/docs-i18n-workflow.svg)

1. 在页面顶部导航栏的右上角，找到带有地球图标的语言选择按钮（默认显示 `🌐 ZH ▾`）；
2. 鼠标点击该按钮，下拉菜单中将列出所有支持的语言选项；
3. 点击你想切换的目标语言（例如 `English` 或 `日本語`）；
4. 页面导航栏按钮、搜索框提示语及版本信息将**瞬间就地刷新**为您选择的语言，当前正文阅读位置完全不受影响，**无需等待页面重新加载白屏**。

---

## 多语言实现的巧妙之处

在很多传统的文档系统中，为了支持 10 种语言，往往需要在编译时生成 10 份重复的静态文件（例如 `/zh/`、`/en/`、`/ja/`），这会导致：
- 静态打包体积成倍膨胀；
- 每次切换语言时整个页面必须强制刷新，重新下载整张网页，用户正在阅读的滚动条位置瞬间丢失；
- 如果某篇文章尚未翻译，切换后容易直接显示 404 页面错误。

EpoCanvas Docs 采用了**前端轻量字典替换方案**：
- 系统统一维护一份精炼的翻译字典（位于 `src/utils/i18n.ts`）；
- 点击切换时，脚本在几毫秒内直接替换页面上带有 `data-i18n` 标记的界面文字；
- 用户的选择会自动保存在浏览器的本地缓存（LocalStorage）中，下一次打开网站时会自动记住你的偏好语言；
- 如果某些词条暂时没有对应语种翻译，系统会自动显示默认的中文回退，绝不发生白屏或崩溃。

## 开发者：如何添加或修改翻译词条？

如果你在二次开发中新增了导航按钮或界面元素，只需要打开 `src/utils/i18n.ts` 补充词条即可：

```typescript
// 文件路径: src/utils/i18n.ts
export const UI_TRANSLATIONS: Record<string, Record<string, string>> = {
  // 新增一个导航条目翻译
  'nav.plugins': {
    'zh-CN': '插件生态',
    'zh-TW': '外掛生態',
    en: 'Plugins',
    ja: 'プラグイン',
    ko: '플러그인',
    de: 'Plugins',
    fr: 'Extensions',
    es: 'Complementos',
    ru: 'Плагины',
    ar: 'الإضافات',
  },
};
```

然后在对应的 `.astro` 模板中为 HTML 标签加上属性即可生效：
```html
<a href="/plugins/" data-i18n="nav.plugins">插件生态</a>
```
简单直接，维护起来非常轻松。

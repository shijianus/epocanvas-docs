# 页面布局与阅读体验

为了给读者提供舒服、高效的阅读体验，**EpoCanvas Docs** 采用了经典而清晰的“三栏式”页面布局。读者在翻阅长篇文章时，随时能掌握“自己在整个站点的哪个位置”以及“正在阅读本文的哪个小节”。

---

## 整体界面分区说明

打开任意一篇文档，页面默认分为四个主要功能区域：

![EpoCanvas Docs 真实三栏式阅读界面截图](/images/canvas/ui-layout-reading.png)

*图：EpoCanvas Docs 实际在浏览器中运行的三栏排版效果，左侧为分类目录，中央为文章正文，右侧为自动生成的大纲。*

![EpoCanvas Docs 布局架构示意图](/images/canvas/docs-layout-3tier.svg)

### 1. 顶部全局导航栏 (Header)
位于页面最上方，固定悬浮，在向下滚动浏览时始终保持可见：
- **站点 Logo 与标题**：左侧展示 EpoCanvas 图标与项目名称，点击可快速回到文档站首页。
- **全局搜索框**：点击或按下快捷键 `Cmd+K` / `Ctrl+K`，即可快速在全站搜索任何关键词。
- **主导航按钮**：提供“首页”、“文档”、“部署”等常用功能快速跳转链接。
- **当前版本徽标**：显示当前文档对应发布的稳定版本号（如 `v1.2.0`），点击可查看 GitHub 上的详细更新记录。
- **多语言切换器**：点击地球图标即可展开支持的 10 种语言，瞬间切换界面显示。
- **深浅色主题切换**：提供太阳/月亮图标，方便在亮色模式和暗色模式间切换。

---

### 2. 左侧分类目录 (Sidebar)
位于页面左侧（电脑端宽度固定约为 288 像素），按照逻辑层级展示所有的文档章节：
- **分类折叠**：相关的文档按分类整理（如“产品概览”、“核心功能”、“文档编写”等），支持清晰的分组展示。
- **当前激活高亮**：当前正在阅读的文章会在左侧菜单中以主题蓝色和加粗字体高亮，并带有圆点标识。
- **滚动条位置记忆**：在很多旧式文档站中，从一篇文章跳转到另一篇时左侧侧边栏会突然跳回顶部；而 EpoCanvas Docs 内置了位置记忆功能，换页时侧边栏滚动条位置保持不变，不会产生视觉跳动。

---

### 3. 中央正文阅读区 (Main Content)
位于屏幕中央，是承载技术文档内容的核心区域：
- **面包屑路径导航**：文章标题上方清晰标注当前文章所在分类层级（如 `文档 / 产品概览与入门 / 页面布局与阅读体验`），方便快速返回上级。
- **适宜的阅读宽度**：正文最大宽度限制在 `54rem`（约 860 像素），避免由于显示器屏幕过宽导致一行字过长、阅读容易串行的问题。
- **底部智能翻页**：每篇文档末尾会自动生成“上一篇”和“下一篇”的卡片按钮，方便读者按推荐顺序连续阅读。

---

### 4. 右侧文章大纲 (Table of Contents)
位于正文右侧（电脑端宽度固定约为 320 像素）：
- **自动抓取标题**：系统会在页面加载时自动解析当前文档中的二级标题（`##`）和三级标题（`###`）并列出大纲。
- **随动高亮追踪**：阅读过程中随着鼠标向下滚动，右侧大纲会自动将视口中正在阅读的小节标记为高亮，帮助读者时刻把握当前篇章结构。
- **点击平滑直达**：点击大纲中的任意小标题，页面会平滑滚动到对应段落，并自动更新浏览器地址栏的锚点 URL（如 `#整体界面分区说明`），方便复制分享。

## 亮色与暗色模式自适应

EpoCanvas Docs 默认采用暗色（Dark）主题设计，背景为舒适的深蓝黑底色，文字采用高对比度的柔和灰白色，降低长时间看屏幕的代码眼部疲劳。

- **跟随系统偏好**：首次打开网页时，站点会自动检测操作系统的偏好设置（若系统设置为浅色，则自动呈现浅色模式）。
- **手动切换与记忆**：点击右上角的主题切换按钮，可以手动在亮暗两种风格间切换，切换结果会自动保存在浏览器的本地缓存中，下次打开依然有效。

## 手机与平板端响应式适配

在手机或平板等不同尺寸的屏幕上，页面会自动调整布局以适应屏幕大小：

| 设备类型 | 屏幕宽度 | 布局表现 |
| :--- | :--- | :--- |
| **宽屏台式机 / 笔记本** | `>= 1152px` | 完整展示标准的**三栏式**布局（左菜单 + 中正文 + 右大纲）。 |
| **平板电脑 / 竖屏窗口** | `768px ~ 1152px` | 右侧大纲自动隐藏（可从正文上方折叠菜单查看），保持左侧导航与正文双栏布局。 |
| **智能手机** | `< 768px` | 左右边栏全部收起，正文全宽展示。点击顶栏右上角的“三道杠”菜单按钮即可滑出侧边栏抽屉。 |

无论是使用超宽屏显示器还是在手机上临时查阅，都能获得自然、舒适的阅读体验。

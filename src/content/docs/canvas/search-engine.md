在查阅大量技术文档时，快速找到想要的配置项或参数至关重要。**EpoCanvas Docs** 内置了**双模式搜索**：顶栏搜索框负责在当前页面内快速定位，`Ctrl+K` 弹窗负责检索全站所有文档。两种搜索全部在浏览器本地完成，不需要任何后端服务，离线环境同样可用。

---

## 两种搜索分别什么时候用？

| 场景 | 用哪种 | 怎么操作 |
| :--- | :--- | :--- |
| 记得某段话就在**当前这篇文章**里 | 页内查找 | 直接点击顶栏搜索框，输入关键词 |
| 不确定内容在**哪篇文章**，需要全站查找 | 全站检索 | 按下 `Ctrl + K`（Mac 为 `Cmd + K`） |

---

## 页内查找：顶栏搜索框

点击页面顶部中间的搜索框（放大镜图标），直接输入关键词：

![顶栏页内查找的真实效果：关键词高亮与匹配计数](/images/canvas/ui-inpage-search.png)

*图：在顶栏搜索框输入"部署"后的实际效果，当前页面中的匹配文字全部高亮，搜索框内显示 `3/9` 计数。*

1. **即时高亮**：输入过程中，当前页面内所有匹配的文字立即加上高亮底色，页面自动滚动到第一处匹配。
2. **匹配计数**：搜索框内显示 `当前第 N 处 / 共 M 处` 的进度计数。
3. **逐个跳转**：按 <kbd>Enter</kbd> 或点击向下箭头跳到下一处匹配；<kbd>Shift + Enter</kbd> 或向上箭头回到上一处。
4. **清除恢复**：按 <kbd>Esc</kbd> 或点击 `×` 按钮，清除高亮并恢复页面原状。

---

## 全站检索：Ctrl+K 弹窗

无论你当前处于哪个页面，按下快捷键 <kbd>Ctrl</kbd> + <kbd>K</kbd>（Mac 为 <kbd>Cmd</kbd> + <kbd>K</kbd>），或点击搜索框右侧的 `Ctrl K` 徽标，屏幕中央会弹出全局检索窗口：

![全站检索弹窗的真实效果：列出命中文档与段落预览](/images/canvas/ui-search-modal.png)

*图：在弹窗中输入"部署"后的实际效果，检索到 9 条结果，按文档分组展示，命中的关键词带高亮。*

1. **输入关键词**：支持中文词组（如"部署"、"组件"）、英文单词以及代码片段（如 `pnpm`、`astro.config.mjs`）。
2. **浏览结果**：结果按文档分组，每条展示文档标题、所在章节以及包含关键词的上下文预览，命中词高亮显示。
3. **键盘操作**：用 <kbd>↑</kbd> <kbd>↓</kbd> 方向键在结果间移动，<kbd>Enter</kbd> 打开选中结果并定位到对应段落，<kbd>Esc</kbd> 关闭弹窗。

## 为什么搜索这么快？

很多网站的文档搜索需要把请求发送到远端服务器的数据库查询，网络不好时只能一直转圈。

EpoCanvas Docs 使用 **Pagefind** 本地静态搜索方案：

1. **打包时提取索引**：执行 `pnpm run build` 时，系统自动抓取每篇文档的内容，生成一组经过压缩的静态索引分片文件。
2. **按需轻量下载**：在搜索框输入文字时，浏览器只拉取对应字符的索引分片（体积仅几 KB 到几十 KB）。
3. **本地即时匹配**：匹配与排序全部在浏览器本地完成，因此没有网络请求延迟，在内网或离线环境中也能完整使用。

## 搜索使用小贴士

- **词组拆分**：想找更精确的内容，可以输入多个词并用空格分开（例如输入 `Cloudflare 域名`）。
- **优先查标题**：文档标题和章节标题在排序中的权重最高，标题命中关键词的结果会排在最前面。
- **开发模式的限制**：`pnpm run dev` 启动的开发服务器不会实时重建全站索引，新写的文章要在全局检索中搜到，需要先执行一次 `pnpm run build`。页内查找不受此限制。

# 全文搜索与快捷键使用

在查阅大量技术文档时，快速找到想要的配置项或参数至关重要。**EpoCanvas Docs** 内置了一套轻快好用的**静态全文搜索引擎**，不需要依赖任何第三方云端搜索平台，在本地浏览器就能秒级响应你的搜索请求。

---

## 如何呼出搜索功能

你可以通过以下两种最直观的方式呼出搜索弹窗：

### 1. 使用键盘全局快捷键
无论你当前处于哪个页面、滚动到了哪一段，直接在键盘上按下组合键：
- **苹果 Mac 设备**：按下 <kbd>⌘ Cmd</kbd> + <kbd>K</kbd>
- **Windows / Linux 设备**：按下 <kbd>Ctrl</kbd> + <kbd>K</kbd>

### 2. 点击顶部搜索栏
直接鼠标点击页面顶部中间的搜索框（带有放大镜图标 `🔍 搜索文档...`），搜索窗口就会立刻从屏幕正中弹出。

---

## 搜索弹窗使用技巧

搜索弹窗弹出后，光标会自动聚焦在输入框中：

![EpoCanvas Docs 搜索功能示意图](/images/canvas/docs-search-engine.svg)

1. **输入关键词**：
   - 支持输入中文（如“部署”、“组件”、“环境变量”）；
   - 支持输入英文单词或代码片段（如 `pnpm`、`Header`、`astro.config.mjs`）。
2. **浏览匹配结果**：
   - 搜索结果会实时列出所有命中的文档。
   - 每条结果清晰展示**文档标题**、**所在章节分类**以及**包含该关键词的正文前后上下文预览**，命中的词语会自动加上黄色高亮底色。
3. **全键盘无鼠标操作**：
   - 按键盘上的方向下键 <kbd>↓</kbd> 和方向上键 <kbd>↑</kbd> 可以在结果列表中快速移动选择。
   - 选中想要查看的内容后，按下回车键 <kbd>Enter</kbd>，即可瞬间跳转到该文档并定位到对应段落。
   - 如果想关闭搜索弹窗，直接按下退出键 <kbd>Esc</kbd>，或者点击弹窗外部的黑色遮罩层即可。

---

## 为什么 EpoCanvas Docs 的搜索这么快？

很多网站的文档搜索需要将请求发送到千里之外的服务器数据库进行查询，一旦网络不好就会一直转圈圈。

EpoCanvas Docs 采用了现代前端流行的 **Pagefind** 本地静态搜索技术：
1. **打包时提取索引**：在执行 `pnpm run build` 生成静态网站时，系统会自动抓取每篇文档的内容，并生成一组经过高压缩的静态索引分片文件保存在本地；
2. **按需轻量下载**：当你首次在搜索框输入文字时，浏览器只会拉取对应字符的微型分片索引（体积仅几 KB 到几十 KB）；
3. **本地毫秒级匹配**：匹配与关键词打分全部在你的浏览器本地瞬间完成，因此不仅没有任何网络卡顿，而且在没有外网的局域网或离线环境中也能完全正常使用。

## 搜索使用小贴士 (Tips)

- **词组拆分**：如果你想找更精确的内容，可以输入多个词，中间用空格分开（例如输入 `Cloudflare 域名`）。
- **优先查标题**：文档的标题和二级小标题在搜索算法中的权重最高，如果搜索结果较多，标题中含有该词的文档会排在最前面。
- **清除重置**：点击搜索输入框右侧的小叉号（`×`）可以一键清空当前输入的关键词。

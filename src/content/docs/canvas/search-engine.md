**EpoCanvas Docs** 提供页内查找和全站检索。视口宽度达到 `64rem` 时，顶栏显示页内输入框；小于 `64rem` 时只显示全站搜索按钮。全站检索使用 Pagefind 静态索引，不需要搜索后端。

---

## 两种搜索分别什么时候用？

| 场景 | 用哪种 | 怎么操作 |
| :--- | :--- | :--- |
| 内容就在**当前文章**中 | 页内查找 | 视口至少 `64rem` 时在顶栏输入；窄屏使用浏览器的“在页面中查找” |
| 不确定内容在**哪篇文章**中 | 全站检索 | 点击顶栏全站搜索按钮，或按 `Ctrl + K`（Mac 为 `Cmd + K`） |

---

## 页内查找：顶栏搜索框

以下操作适用于视口宽度至少 `64rem` 的页面。点击顶栏页内输入框，输入关键词。小于此宽度时，输入框、计数和跳转控件都隐藏，只保留打开全站检索的放大镜按钮；查找当前页请用浏览器自带的查找功能。

![顶栏页内查找的标注图：① 输入框 ② 匹配计数 ③ 上下跳转 ④ 清除 ⑤ 页面高亮](/images/canvas/ui-inpage-search.png)

*图：页内查找的既有截图，仅供识别功能。当前匹配计数、上一个/下一个和清除控件显示在输入框下方，不在框内；窄屏不显示这些控件。截图中的位置、计数或布局若与当前界面不同，以实际界面为准。*

### 输入关键词

可输入中文词组、英文单词或代码片段，如 `pnpm`、`astro.config.mjs`。输入后，正文中可匹配的可见文字会高亮，并滚动到第一处匹配；导航和隐藏内容不在查找范围内。

### 在匹配结果之间跳转

- 输入框有焦点时按 <kbd>Enter</kbd>，或点击向下箭头按钮：跳到下一处匹配；
- 输入框有焦点时按 <kbd>Shift + Enter</kbd>，或点击向上箭头按钮：回到上一处匹配；
- 输入框下方的控件显示 `N/M` 计数（如 `3/9`），表示当前匹配序号和总数。

### 清除搜索恢复页面

输入框有焦点时按 <kbd>Esc</kbd>，或点击清除按钮 `×`，清空关键词并移除高亮。

## 全站检索：Ctrl+K 弹窗

按 <kbd>Ctrl</kbd> + <kbd>K</kbd>（Mac 为 <kbd>Cmd</kbd> + <kbd>K</kbd>），或点击顶栏的全站搜索按钮打开弹窗。宽屏按钮显示快捷键徽标；小于 `64rem` 时显示放大镜图标，点击后仍是全站检索，不是页内输入。

![全站检索弹窗的标注图：① 触发徽标 ② 检索输入框 ③ 结果列表 ④ 快捷键栏](/images/canvas/ui-search-modal.png)

*图：全站检索的既有截图，展示输入框和结果列表。截图中的按钮位置或快捷键提示若与当前布局不同，以实际界面和下文操作为准；当前使用 Tab 聚焦链接，窄屏可能不显示底部提示栏。*

### 输入关键词

输入当前页面语言中的词组、英文单词或代码片段，例如 `pnpm`、`astro.config.mjs`。Pagefind 根据相关性排列结果，标题命中并不保证始终排在最前。

### 浏览结果列表

结果按文档组织，显示标题、匹配摘要以及可用的章节子结果，关键词带高亮。文档标题与子结果是链接：点击标题打开文档，点击子结果按链接锚点进入相应章节。标题不是展开/折叠按钮。

### 用键盘完成整个流程

- <kbd>Tab</kbd> / <kbd>Shift + Tab</kbd>：在输入框、按钮与结果链接之间顺序移动焦点；
- 结果链接有焦点时按 <kbd>Enter</kbd>：打开该链接；章节链接按其锚点定位；
- <kbd>Esc</kbd>：关闭弹窗。

当前 Pagefind 界面不支持用 <kbd>↑</kbd> / <kbd>↓</kbd> 选择结果，也不支持点击文档标题展开命中段落。

## 为什么搜索这么快？

![EpoCanvas Docs 双模式搜索机制对比图：左侧顶栏页内查找（DOM 遍历高亮、实时计数与平滑滚动），右侧全站检索弹窗（Ctrl+K 唤起、Pagefind WASM 内存倒排索引秒级匹配）](/images/canvas/docs-search-flow.svg)

*图：双模式搜索工作机制对比。左为顶栏页内关键词快速定位，右为基于 Pagefind WASM 的全站静态索引检索，两者均完全在浏览器本地运行。*

很多网站的文档搜索需要把请求发送到远端服务器的数据库查询，网络不好时只能一直转圈。

EpoCanvas Docs 使用 **Pagefind** 本地静态搜索方案：

1. **打包时提取索引**：执行 `pnpm run build` 时，系统自动抓取每篇文档的内容，生成一组经过压缩的静态索引分片文件。
2. **按需下载索引**：浏览器从本站加载搜索程序和所需索引分片；首次加载或缺少缓存时仍有网络请求。
3. **浏览器内匹配**：索引载入后，匹配与排序在浏览器中完成。内网部署须同时提供搜索资源，不能把本地计算理解为首次访问无需网络。

## 搜索使用小贴士

- **词组拆分**：想找更精确的内容，可以输入多个词并用空格分开（例如输入 `Cloudflare 域名`）。
- **使用具体词语**：标题和章节名有助于缩小范围，结果顺序仍以 Pagefind 的相关性排序为准。
- **开发模式的限制**：全站检索的索引只在构建时生成，`pnpm run dev` 启动的开发服务器里 `Ctrl + K` 弹窗不加载索引、无法使用；要验证搜索效果，先执行 `pnpm run build`，再运行 `pnpm run preview` 访问构建产物。页内查找不受此限制。

**EpoCanvas Docs** 提供頁內查找與全站檢索。視窗寬度至少 `64rem` 時，頂欄顯示頁內輸入框；小於 `64rem` 時只顯示全站搜尋按鈕。全站檢索使用 Pagefind 靜態索引，不需要搜尋後端。

---

## 兩種搜尋分別什麼時候用？

| 情境 | 用哪種 | 怎麼操作 |
| :--- | :--- | :--- |
| 內容就在**目前文章**中 | 頁內查找 | 至少 `64rem` 時在頂欄輸入；窄螢幕使用瀏覽器的「在頁面中尋找」 |
| 不確定內容在**哪篇文章** | 全站檢索 | 點擊頂欄全站搜尋按鈕，或按 `Ctrl + K`（Mac 為 `Cmd + K`） |

---

## 頁內查找：頂欄搜尋框

以下操作適用於寬度至少 `64rem` 的視窗。點擊頂欄頁內輸入框並輸入關鍵字。小於此寬度時，輸入框、計數與跳轉控制項都隱藏，只保留開啟全站檢索的放大鏡按鈕；查找目前文章請使用瀏覽器內建功能。

![頂欄頁內查找的標註圖：① 輸入框 ② 匹配計數 ③ 上下跳轉 ④ 清除 ⑤ 頁面高亮](/images/canvas/ui-inpage-search.png)

*圖：既有頁內查找截圖，僅供識別功能。目前計數、上一個/下一個與清除控制項位於輸入框下方，不在框內；窄螢幕不顯示這些控制項。截圖的位置、計數或版面若與目前介面不同，以實際介面為準。*

### 輸入關鍵字

可輸入中文詞組、英文單字或程式碼片段，例如 `pnpm`、`astro.config.mjs`。內文中符合的可見文字會反白，並捲動到第一處；導覽與隱藏內容不在查找範圍內。

### 在匹配結果之間跳轉

- 輸入框有焦點時按 <kbd>Enter</kbd>，或點擊向下箭頭按鈕：移至下一處；
- 輸入框有焦點時按 <kbd>Shift + Enter</kbd>，或點擊向上箭頭按鈕：移至上一處；
- 輸入框下方的控制項顯示 `N/M` 計數（例如 `3/9`），代表目前序號與總數。

### 清除搜尋恢復頁面

輸入框有焦點時按 <kbd>Esc</kbd>，或點擊 `×` 清除按鈕，清空關鍵字並移除反白。

## 全站檢索：Ctrl+K 彈窗

按 <kbd>Ctrl</kbd> + <kbd>K</kbd>（Mac 為 <kbd>Cmd</kbd> + <kbd>K</kbd>），或點擊頂欄全站搜尋按鈕。寬螢幕顯示快捷鍵徽標；小於 `64rem` 時顯示放大鏡圖示，點擊後仍是全站檢索，不是頁內輸入。

![全站檢索彈窗的標註圖：① 觸發徽標 ② 檢索輸入框 ③ 結果列表 ④ 快捷鍵欄](/images/canvas/ui-search-modal.png)

*圖：既有全站檢索截圖，展示輸入框與結果。按鈕位置或快捷鍵提示若與目前版面不同，以實際介面及下文為準。目前使用 Tab 聚焦連結；窄螢幕可能不顯示底部提示列。*

### 輸入關鍵字

輸入目前頁面語言的詞組或 `pnpm`、`astro.config.mjs` 等程式碼片段。Pagefind 依相關性排序，標題符合並不保證排在最前。

### 瀏覽結果列表

結果依文件組織，顯示標題、符合摘要與可用的章節子結果，關鍵字會反白。標題與子結果都是連結：標題開啟文件，章節連結依錨點定位。標題不是展開/摺疊按鈕。

### 用鍵盤完成整個流程

- <kbd>Tab</kbd> / <kbd>Shift + Tab</kbd>：在輸入框、按鈕與結果連結間依序移動焦點；
- 結果連結有焦點時按 <kbd>Enter</kbd>：開啟該連結；章節連結依其錨點定位；
- <kbd>Esc</kbd>：關閉彈窗。

目前 Pagefind 介面不支援以 <kbd>↑</kbd> / <kbd>↓</kbd> 選擇結果，也不支援點擊文件標題展開符合段落。

## 為什麼搜尋這麼快？

![EpoCanvas Docs 雙模式搜尋機制對比圖：左側頂欄頁內查找（DOM 走訪高亮、即時計數與平滑捲動），右側全站檢索彈窗（Ctrl+K 喚起、Pagefind WASM 記憶體倒排索引秒級匹配）](/images/canvas/docs-search-flow.svg)

*圖：雙模式搜尋工作機制對比。左為頂欄頁內關鍵字快速定位，右為基於 Pagefind WASM 的全站靜態索引檢索，兩者均完全在瀏覽器本機執行。*

很多網站的文件搜尋需要把請求傳送到遠端伺服器的資料庫查詢，網路不好時只能一直轉圈。

EpoCanvas Docs 使用 **Pagefind** 本機靜態搜尋方案：

1. **打包時擷取索引**：執行 `pnpm run build` 時，系統自動擷取每篇文件的內容，產生一組經過壓縮的靜態索引分片檔案。
2. **按需下載索引**：瀏覽器從本站載入搜尋程式與所需索引分片；首次載入或快取不足時仍有網路請求。
3. **瀏覽器內比對**：索引載入後，比對與排序在瀏覽器完成。內部網路部署也須提供搜尋資源；本機運算不代表首次存取無須網路。

## 搜尋使用小技巧

- **詞組拆分**：想找更精確的內容，可以輸入多個詞並用空格分開（例如輸入 `Cloudflare 網域`）。
- **使用具體詞語**：標題與章節名稱有助縮小範圍，順序仍以 Pagefind 相關性排序為準。
- **開發模式的限制**：全站檢索的索引只在建置時產生，`pnpm run dev` 啟動的開發伺服器裡 `Ctrl + K` 彈窗不會載入索引、無法使用；要驗證搜尋效果，先執行 `pnpm run build`，再執行 `pnpm run preview` 開啟建置結果。頁內查找不受此限制。

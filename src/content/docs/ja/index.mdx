## クイックナビゲーションと機能ガイド

<CardGrid stagger>
	<Card title="製品概要とコアバリュー" icon="laptop">
		EpoCanvas Docs が生まれた背景、解決する課題、コア機能、そして他の主要ドキュメントツールとの実際の違いを紹介します。

	<Card title="3分でクイックスタート" icon="rocket">
		数行のコマンドでローカル PC に依存関係をインストールし、ホットリロード対応の開発サーバーを起動。Markdown を書きながらリアルタイムでプレビューできます。環境をインストールしたくない場合は、ワンクリックデプロイボタンでサンプルサイトを自分のクラウドアカウントに直接公開することもできます。
		<LinkCard title="クイックスタートガイドを見る" href="/ja/canvas/deployment/" description="ワンクリックデプロイボタン、インストール手順、よく使うコマンド。" />
	</Card>
	<Card title="閲覧画面と操作体験" icon="document">
		「左側のカテゴリナビゲーション + 中央の本文 + 右側のこのページの目次」という見やすい 3 カラム構成。ページを移動してもスクロール位置が保たれ、スマートフォンにも PC にも自動で対応します。
		<LinkCard title="画面レイアウトを見る" href="/ja/canvas/layout/" description="3 カラムレイアウトの構造、テーマの切り替え、文字組み。" />
	</Card>
	<Card title="ページ内検索とサイト全体検索" icon="magnifier">
		トップバーの検索ボックスで現在のページの内容を探し、Ctrl+K / Cmd+K でサイト全体検索のポップアップを開けます。すべてブラウザ内でローカルに処理されます。
		<LinkCard title="検索機能を見る" href="/ja/canvas/search-engine/" description="2 つの検索モードの使い方とローカルインデックスの仕組み。" />
	</Card>
	<Card title="10 言語の完全翻訳" icon="translate">
		ナビゲーション、サイドバー、各ドキュメントの本文は、簡体字中国語、繁体字中国語、英語、日本語など 10 言語で提供されます。ページ右上で言語をクリックするだけで、同じ記事の目的言語版に移動できます。
		<LinkCard title="多言語システムを見る" href="/ja/canvas/i18n/" description="対応言語の一覧、切り替え方法、翻訳追加の手順。" />
	</Card>
	<Card title="Markdown 執筆ガイド" icon="pencil">

		<LinkCard title="整形ガイドを読む" href="/ja/canvas/markdown/" description="基礎フォーマットと拡張構文の全体像。" />
	</Card>
	<Card title="レンダリングルールの詳細" icon="setting">

		<LinkCard title="レンダリングルールを見る" href="/ja/canvas/rendering/" description="レンダリングパイプライン、構文の約束事、よくある間違い。" />
	</Card>

		<LinkCard title="コンポーネント体系を見る" href="/ja/canvas/components/" description="コンポーネント構成、実装の詳細、アップグレード時の回帰確認。" />
	</Card>
	<Card title="よくあるカスタマイズ早見表" icon="pencil">

		<LinkCard title="カスタマイズ早見表を見る" href="/ja/canvas/recipes/" description="8 つのレシピの完全な操作手順。" />

**EpoCanvas Docs** предлагает поиск по странице и по сайту. При ширине окна от `64rem` в верхней панели видно поле ввода; ниже `64rem` остаётся только кнопка поиска по сайту. Он использует статический индекс Pagefind без поискового сервера.

---

## Какой режим поиска когда использовать?

| Ситуация | Какой режим | Как действовать |
| :--- | :--- | :--- |
| Текст находится в **текущей статье** | Поиск по странице | Поле в панели при ширине от `64rem`; на узком экране — поиск по странице в браузере |
| Неизвестно, **в какой статье** искать | Поиск по сайту | Кнопка в панели или `Ctrl + K` (Mac: `Cmd + K`) |

---

## Поиск по странице: поле поиска в верхней панели

Эти действия доступны при ширине окна от `64rem`. Введите запрос в верхнее поле. При меньшей ширине поле, счётчик и кнопки перехода скрыты; остаётся только лупа, открывающая поиск по сайту. Для текущей статьи используйте поиск по странице в браузере.

![Аннотированная схема поиска по странице в верхней панели: ① поле ввода ② счётчик совпадений ③ переход вверх/вниз ④ очистка ⑤ подсветка на странице](/images/canvas/ui-inpage-search.png)

*Рисунок: существующий снимок для ориентира. Сейчас счётчик, кнопки перехода и очистки находятся под полем, а не внутри него, и скрыты на узких экранах. Если положение, числа или компоновка отличаются, ориентируйтесь на реальный интерфейс.*

### Ввод ключевых слов

Введите слова или код, например `pnpm` и `astro.config.mjs`. Видимые совпадения в основном тексте подсвечиваются, страница переходит к первому. Навигация и скрытые элементы не участвуют.

### Переход между совпадениями

- При фокусе в поле <kbd>Enter</kbd> или кнопка со стрелкой вниз: следующее совпадение;
- При фокусе в поле <kbd>Shift + Enter</kbd> или кнопка со стрелкой вверх: предыдущее совпадение;
- Под полем счётчик `N/M` (например `3/9`) показывает текущее совпадение и общее число.

### Очистка поиска и восстановление страницы

При фокусе в поле нажмите <kbd>Esc</kbd> либо кнопку `×`, чтобы очистить запрос и подсветку.

## Поиск по всему сайту: окно Ctrl+K

Нажмите <kbd>Ctrl</kbd> + <kbd>K</kbd> (Mac: <kbd>Cmd</kbd> + <kbd>K</kbd>) или кнопку поиска в панели. На широком экране она показывает сочетание клавиш, ниже `64rem` — лупу. В обоих случаях открывается поиск по сайту, а не поле поиска по странице.

![Аннотированная схема окна поиска по сайту: ① бейдж вызова ② поле ввода запроса ③ список результатов ④ панель горячих клавиш](/images/canvas/ui-search-modal.png)

*Рисунок: существующий снимок поля и результатов. Если кнопки или подсказки клавиш не совпадают с текущей компоновкой, следуйте реальному интерфейсу и описанию ниже. Сейчас Tab переводит фокус на ссылки; нижние подсказки могут быть скрыты на узких экранах.*

### Ввод ключевых слов

Введите слова на языке страницы или код, например `pnpm` и `astro.config.mjs`. Pagefind сортирует по релевантности; совпадение в заголовке не гарантирует первое место.

### Просмотр списка результатов

Результаты сгруппированы по документам: заголовок, фрагмент текста и доступные результаты разделов. Заголовки и разделы — ссылки. Заголовок открывает документ, ссылка раздела ведёт к якорю. Заголовок не служит кнопкой раскрытия или сворачивания.

### Весь процесс с клавиатуры

- <kbd>Tab</kbd> / <kbd>Shift + Tab</kbd>: последовательно перемещать фокус между полями, кнопками и ссылками результатов;
- При фокусе на ссылке <kbd>Enter</kbd>: открыть её; ссылки разделов ведут к своим якорям;
- <kbd>Esc</kbd>: закрыть окно.

Текущий интерфейс Pagefind не выбирает результаты клавишами <kbd>↑</kbd> / <kbd>↓</kbd> и не раскрывает найденные фрагменты по нажатию на заголовок документа.

## Почему поиск такой быстрый?

![Сравнительная схема двухрежимного поиска EpoCanvas Docs: слева поиск по странице в верхней панели (обход DOM с подсветкой, счётчик в реальном времени и плавная прокрутка), справа окно поиска по сайту (вызов через Ctrl+K, сопоставление за секунды по инвертированному индексу Pagefind WASM в памяти)](/images/canvas/docs-search-flow.svg)

*Рисунок: сравнение механизмов работы двухрежимного поиска. Слева — быстрый поиск ключевых слов по текущей странице в верхней панели; справа — поиск по статическому индексу всего сайта на основе Pagefind WASM. Оба режима работают полностью локально в браузере.*

У многих сайтов поиск по документации отправляет запрос в базу данных на удалённом сервере, и при плохой сети приходится бесконечно смотреть на индикатор загрузки.

EpoCanvas Docs использует локальное статическое решение для поиска — **Pagefind**:

1. **Извлечение индекса при сборке**: во время выполнения `pnpm run build` система автоматически собирает содержимое каждого документа и генерирует набор сжатых статических файлов-шардов индекса.
2. **Загрузка по требованию**: браузер получает с сайта поисковый код и нужные части индекса. Первая загрузка или отсутствие кеша по-прежнему требуют сетевых запросов.
3. **Поиск в браузере**: после загрузки индекса поиск и сортировка выполняются локально. Интранет тоже должен отдавать поисковые файлы; это не означает, что первое посещение работает без сети.

## Советы по использованию поиска

- **Разбивка на слова**: для более точного поиска введите несколько слов через пробел (например, `Cloudflare домен`).
- **Используйте точные термины**: названия документов и разделов помогают сузить поиск; порядок определяет Pagefind по релевантности.
- **Ограничение режима разработки**: индекс всего сайта создаётся только при сборке; в сервере разработки, запущенном через `pnpm run dev`, диалог `Ctrl+K` не загружает индекс, поэтому глобальный поиск там недоступен. Чтобы проверить поиск, выполните `pnpm run build`, а затем `pnpm run preview`. Поиск по странице этого ограничения не касается.

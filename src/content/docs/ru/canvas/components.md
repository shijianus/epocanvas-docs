Интерфейс **EpoCanvas Docs** написан не с нуля, а построен на нативных компонентах Starlight с помощью **точечного переопределения**: сохранены каркас страниц и обработка контента Starlight, а отображаемые компоненты — верхняя панель, боковая панель, оглавление, поиск и т.д. — заменены, чтобы получить нужную трёхколоночную раскладку и поведение. На этой странице описана структура этой системы компонентов и способы её изменения.

---

## Механизм переопределения компонентов

Регистрируйте замены в `components` в `astro.config.mjs`, как показано ниже; полный список определяет текущая конфигурация.

```javascript
// astro.config.mjs (фрагмент)
components: {
  Header: './src/components/starlight/Header.astro',
  MobileMenuToggle: './src/components/starlight/MobileMenuToggle.astro',
  Sidebar: './src/components/starlight/Sidebar.astro',
  TableOfContents: './src/components/starlight/TableOfContents.astro',
  PageTitle: './src/components/starlight/PageTitle.astro',
  TwoColumnContent: './src/components/starlight/TwoColumnContent.astro',
  Search: './src/components/starlight/Search.astro',
  Pagination: './src/components/starlight/Pagination.astro',
  Footer: './src/components/starlight/Footer.astro',
  SkipLink: './src/components/starlight/SkipLink.astro',
},
```

При сборке зарегистрированные замены имеют приоритет. Остальные компоненты используют нативную реализацию Starlight.

## Назначение пользовательских компонентов

Исходники находятся в `src/components/starlight/`; основные задачи перечислены ниже.

| Файл компонента | Назначение |
| :--- | :--- |
| `Header.astro` | Всё содержимое верхней панели: логотип, поле поиска, основная навигация, значок версии, переключатель языка, переключатель темы, ссылки на GitHub и Telegram |
| `Search.astro` | Поиск с двумя режимами: поиск по странице в верхней панели (подсветка и счётчик) + всплывающее окно поиска по всему сайту на `Ctrl+K` (Pagefind UI) |
| `Pagination.astro` | Карточки «Предыдущая / Следующая страница» внизу: плоская тонкая рамка, заголовок фирменного цвета, косые стрелки ↙/↘, указывающие направление перехода |
| `TwoColumnContent.astro` | Двухколоночный каркас из основного текста и оглавления справа; управляет фиксированной шириной правой колонки и её прокруткой |
| `TableOfContents.astro` | Заголовок «Содержание страницы», значок и список оглавления; отфильтровывает заголовок самой страницы |
| `PageTitle.astro` | Навигационная цепочка, крупный заголовок страницы (берётся из `title` во Frontmatter) и отметка времени «последнее обновление» |
| `Sidebar.astro` | Тонкая обёртка: переиспользует нативный компонент Starlight `SidebarPersister`, благодаря чему позиция прокрутки боковой панели сохраняется при переходе между страницами |
| `SkipLink.astro` | Показывает ссылку перехода при фокусе с клавиатуры и переводит фокус к заголовку `_top` |
| `MobileMenuToggle.astro` | Переключает мобильную боковую панель, синхронизирует состояние и закрывает по Esc с возвратом фокуса |
| `ThemeProvider.astro` | Встроенный скрипт применяет сохранённую или системную тему до загрузки CSS, предотвращая мерцание |
| `Footer.astro` | Подвал: редактировать страницу, сообщить о проблеме, наверх и переход предыдущая/следующая |

## Поток данных: три конфигурационных файла управляют всем интерфейсом

Кастомные компоненты сами по себе не содержат бизнес-данных; содержимое интерфейса управляется тремя конфигурационными файлами:

```text
astro.config.mjs ──→ массивы locales + sidebar ──→ Sidebar.astro рендерит каталог слева (для каждого языка берётся соответствующий перевод)
src/config/navigation.ts ──→ navigationConfig ──→ Header.astro рендерит верхнюю навигацию и подсветку (ссылки автоматически получают языковой префикс)
src/utils/i18n.ts ──→ словарь UI_TRANSLATIONS ──→ компоненты получают строки на текущем языке на этапе сборки
```

- **Каталог слева** распознаёт только объявления `sidebar` из `astro.config.mjs`, и новые документы обязательно нужно регистрировать здесь; поле `translations` каждого пункта содержит тексты меню на 10 языках;
- **Верхняя навигация**: отображаемый текст каждого пункта берётся из словаря `i18n.ts` по ключу `labelKey`, а функция `match` определяет, какая кнопка подсвечивается на текущей странице (перед сопоставлением языковой префикс удаляется);
- **Тексты интерфейса** (плейсхолдер поля поиска, заголовок «Содержание страницы», подсказка переключателя темы и т.п.) каждый компонент выводит на нужном языке напрямую на этапе сборки через `getTranslation(key, lang)`; скриптов подмены в рантайме на странице нет.

Иными словами: чтобы изменить содержимое интерфейса, сначала найдите соответствующий конфигурационный файл; исходный код компонентов нужно трогать только при изменении внешнего вида (отступов, цветов, значков).

## Ключевые детали реализации компонентов

### PageTitle: заголовок страницы и фактическое время обновления

Заголовок страницы читается из `title` во Frontmatter, поэтому **не добавляйте заголовок первого уровня `#` в основной текст**. При `lastUpdated: true` в `astro.config.mjs`, если дата не переопределена во Frontmatter, сборка читает время последнего коммита Git, изменившего этот файл. Это не время каждого коммита репозитория или каждой сборки; изменения других файлов не обновляют дату этой страницы.

:::caution
У нового незакоммиченного документа нет доступной истории Git, поэтому дата не отображается. Незакоммиченные правки существующего файла также не меняют дату его коммита. Неглубокий клон (например, `fetch-depth: 1`) может вернуть дату граничного коммита усечённой истории или не вернуть дату; это не полная история. Для точных дат используйте полную историю Git (`fetch-depth: 0` в CI). Ошибка чтения даты не прерывает сборку.
:::

### Sidebar: как реализовано запоминание позиции прокрутки

`Sidebar.astro` использует `SidebarPersister` из Starlight для восстановления прокрутки после перехода между страницами. `MobileMenuToggle.astro` управляет состоянием и фокусом мобильного меню.

### TableOfContents: генерация содержания страницы

Данные оглавления Starlight генерирует на этапе сборки, разбирая заголовки в тексте (`##` и `###`); компонент лишь отфильтровывает сам заголовок страницы и выполняет рендеринг. Подсветку при прокрутке выполняет в браузере пользовательский элемент `starlight-toc`, без использования каких-либо фреймворков.

### TwoColumnContent: единственный источник ширины правой колонки

Ширина колонки оглавления справа зафиксирована на `20rem` при `@media (min-width: 72rem)` (и `21rem` на сверхшироких экранах от `90rem`); максимальная ширина области основного текста соответственно уменьшается на ширину правой колонки. Чтобы изменить ширину правой колонки, правьте только этот файл — не переопределяйте её кусками в других таблицах стилей.

### Header: навигация, тема и язык

- Кнопки навигации рендерятся в цикле по `navigationConfig`; стиль активного состояния определяется значением, возвращаемым функцией `match`, а ссылки через `localizedHref()` автоматически получают префикс текущего языка;
- Переключатель темы записывает ключ `starlight-theme` в LocalStorage; при загрузке страницы начальная тема выбирается в порядке «локальный выбор → системные настройки»;
- Каждый пункт выпадающего списка языков — реальная ссылка на версию текущей страницы на соответствующем языке: клик сразу выполняет переход, дополнительного хранения состояния нет;
- Оба значка справа в верхней панели — GitHub и Telegram — жёстко прописаны в `src/components/starlight/Header.astro`, поэтому адрес меняют правкой этого файла. Telegram указывает на страницу аккаунта `@epocanvas`, а всплывающая подсказка берётся из строки `social.telegram`. Запись `social` в `astro.config.mjs` управляет отдельной группой значков внизу боковой панели; они друг на друга не влияют.

### Search: поиск в двух режимах

В одном компоненте реализованы две системы поиска (подробнее — в разделе [Полнотекстовый поиск и горячие клавиши](/canvas/search-engine/)):

1. **Поиск по странице**: поле в верхней панели; Enter перемещает между совпадениями на текущей странице, подсветка реализована скриптом, который расставляет отметки;
2. **Поиск по всему сайту**: всплывающее окно `<dialog>` со стандартным интерфейсом Pagefind; индекс генерируется на этапе `pnpm run build`.

Поле поиска по странице видно только от `64rem`; ниже остаётся кнопка поиска по сайту. Для статьи используйте поиск по странице в браузере. При отличиях от снимков ориентируйтесь на текущий интерфейс.

### Pagination: карточки перехода между страницами

Данные «предыдущая / следующая страница» Starlight вычисляет на этапе сборки в соответствии с порядком `sidebar` (`Astro.locals.starlightRoute.pagination`); компонент только рендерит: две равные по ширине карточки, тонкая рамка без тени, заголовок фирменного цвета, косые стрелки ↙ / ↘ при наведении сдвигаются в направлении перехода. Стрелки представляют собой инлайновые SVG-пути, и если сайт используется на языке с письмом RTL, их направление зеркалится автоматически.

## Важные замечания по доработке

:::caution
Переопределяя компоненты, вы отказываетесь от будущих обновлений нативных компонентов Starlight. При обновлении версии Starlight могут измениться props компонентов и структура `Astro.locals.starlightRoute`, поэтому после обновления обязательно проведите регрессионное тестирование всех переопределённых компонентов.
:::

- **Для изменения стилей в первую очередь используйте CSS-переменные**: цвета, шрифты и размеры макета собраны в переменных `:root` в `src/styles/custom.css`, см. [Конфигурация сайта и настройка стилей](/canvas/configuration/); большинство кастомизаций не требуют изменения компонентов;
- **Компоненты трогайте только при изменении поведения**: добавляя кнопки или меняя структуру, получайте тексты интерфейса через `getTranslation(key, lang)` и дополняйте словарь в `i18n.ts` строками на всех 10 языках — для пропущенных языков будет использоваться резервный механизм с отображением на китайском;
- **После изменений обязательно проверяйте локально**: `pnpm run dev` для проверки поведения, `pnpm run verify` для подтверждения успешного прохождения проверки типов и сборки (локальные команды описаны в [Частых вопросах и устранении неполадок](/canvas/troubleshooting/)).

Конкретные типовые операции по кастомизации смотрите прямо в [Шпаргалке по типовым доработкам](/canvas/recipes/).
